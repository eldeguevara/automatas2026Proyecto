# Simulador de Máquina Expendedora

Proyecto del curso Autómatas y Lenguajes Formales (2026). Simulador en Java Swing con un lenguaje de instrucciones propio (`.vm`), analizador léxico, sintáctico y semántico, autómata finito de compra (E0–E5) e importación y exportación JSON.

- **Abrir en NetBeans:** File → Open Project → esta carpeta → F6.
- **Requisitos:** Java 17 o superior. No usa librerías externas.
- **Manual de usuario:** [Manual_de_usuario.pdf](Manual_de_usuario.pdf)
- **Ejemplos:** carpeta [`ejemplos/`](ejemplos/).
